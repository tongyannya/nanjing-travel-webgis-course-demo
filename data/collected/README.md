# 数据收集汇总表

这些工作簿用于阅读、录屏和课程展示。数据范围与当前程序收录范围一致；景点公开表按原工作簿当前可见列整理，其余表依据当前正式JSON汇总。

| 工作簿 | 内容 |
|---|---|
| [景点数据收集汇总.xlsx](景点数据收集汇总.xlsx) | 40个景点、15列，包括编号、名称、游玩时长、成人／学生／儿童参考票价、优惠规则、预约渠道、简介、看点及资料来源 |
| [普通餐饮采样与门店汇总.xlsx](普通餐饮采样与门店汇总.xlsx) | 461个采样格的600米内有效样本数、图层分档与采样上限标记；另页列出15819家去重门店 |
| [南京特色餐饮收集汇总.xlsx](南京特色餐饮收集汇总.xlsx) | 1670家门店，包括1505家南京鸭、165家南京特色菜；保留位置、类别、用餐类型、菜品、营业时间和人均消费提示 |
| [景点图片来源汇总.xlsx](景点图片来源汇总.xlsx) | 40个景点照片的资源路径、来源网页和来源单位 |
| [地铁资料汇总.xlsx](地铁资料汇总.xlsx) | 8条线路、175个站点、主要站点说明、邻近景点及资料来源 |
| [鸭文化资料来源汇总.xlsx](鸭文化资料来源汇总.xlsx) | 8个文化条目的摘要及66条引用对应关系，包含来源网页和核实日期 |

景点原表的22个隐藏列已移除，包括老人票列、收集人员、内部备注和检查状态；填写说明、字段字典和示例等工作页未收录。票价说明保留实际优惠规则，去除附加的原表记录和填写过程表述。其他表按程序使用字段整理，没有个人分工、人工复核过程、原始响应路径、批注或隐藏行列。

每张表提供筛选，并冻结表头和前两列。经纬度为GCJ-02，金额单位为人民币元。空白表示原资料未提供，不能作为零处理；原有参考价格、营业时间和核实日期保持。

普通餐饮数量是固定采样中心600米圆内、按既定分页及过滤规则取得的样本，不是区域餐馆总数。461格累计17639个成员关系，去重后15819家；同一门店可被相邻采样圆共同计入。特色餐饮中的鸭菜类型保留“公开资料推断”等限定，正餐候选与熟食外带分别标注。

程序读取`data/formal/`中的JSON。更新这些Excel后，如需影响页面和排程，应同步核对正式JSON；采集方法见[数据来源与制作说明](../../docs/数据来源与制作说明.md)。
